# Hermes Evolution

Hermes Agent 从 v0.1 到 v0.20 的版本演进报告。

## 在线访问

https://deepgreenuniverse.github.io/hermes_evolution/

## 报告内容

- 20 个主版本的核心变化
- 4 个演进阶段：能力地基、运行扩展、自主协作、产品化界面
- 每版包含版本定位、关键升级与官方 Release 链接
- 支持按演进阶段筛选

## 本地预览

```bash
python3 -m http.server 8420
```

然后访问：http://127.0.0.1:8420

## 数据来源

内容依据 [Hermes Agent 官方仓库](https://github.com/NousResearch/hermes-agent) 与 [GitHub Releases](https://github.com/NousResearch/hermes-agent/releases) 整理。

> 官方版本化从 v0.2.0 开始；报告中的 v0.1 为 v0.2 之前公开开发阶段的归纳。
